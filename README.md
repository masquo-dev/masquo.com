# masquo.com

Source of [masquo.com](https://masquo.com): the site of Masquo, freelance builder of websites and online stores,
automations (n8n, Make, Zapier, Python), Excel and Google Sheets dashboards, and Android apps.

Plain HTML, CSS and JavaScript (no library), hosted on GitHub Pages. English and French.
The contact form is sent to a small private Cloudflare service, protected by Cloudflare Turnstile.
The demo projects (`lagoa/`, `brume/`, `solaria/`) use fictional brands and demonstration data.
